# CPS222 HW6 - Red-Black Tree (Part 1)

An implementation of a self-balancing Red-Black Tree in C++ featuring insertion, recoloring, rotations, recursive string serialization (`ToInfixString`, `ToPrefixString`, `ToPostfixString`), deep copy constructor, search, size tracking, and minimum/maximum queries.

## How to Compile and Run (WSL / Linux)

Compile all test executables:
```bash
make clean
make all
```

Run test suites:
```bash
./first-step
./rbt-tests
```

## Cleaning Build Artifacts
```bash
make clean
```
